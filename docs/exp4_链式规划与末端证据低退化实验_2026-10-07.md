# exp4 链式规划与末端证据的小批量优化

## 范围与对照

本轮命名为 `failure_focused`，继续针对上一轮识别的主要失败机制：Hotpot桥接的实体限定与末端选择、2Wiki桥接比较／组合的完整分支、MuSiQue三四跳的显式中间关系与末端证据。

原始exp4作为每个阶段同样本的对照。五方案均复用现有三个公共索引；算法只使用问题文本、生成的计划与引用、已授权的benchmark跳数。答案、gold文档、type、MuSiQue分解不传入检索算法。结构标签只用于离线采样和评价。

## 五个固定方案

| 名称 | 实际改动 |
|---|---|
| terminal_tail | 原规划；将完整获胜链的末端引用文档提前到第6–10位，最多两篇、只考虑原前20位，原Top5固定 |
| terminal_prefix | 原规划；完整获胜链的末端文档若在原第6–10位，最多两篇进入第3–5位；原Top2固定，原Top10、Top200集合不变 |
| plan_prune | 沿用上一轮问题结构路由，确定性删除已取得对应属性、只比较已有答案的终端计算节点，前序证据节点保留 |
| chain_atomic | 三四跳或明确嵌套实体描述使用原子链提示词；保留并行比较规划，同时启用上述比较剪枝 |
| chain_terminal | chain_atomic与terminal_prefix共同启用 |

末端选择要求同一获胜绑定分支、连续原文引用、字面答案、有限且至少0.85的置信字段、完整祖先证据链。已有本地关系规则检查实体、关系与属性归属；未知关系只允许有限的明确同句关系构式。置信字段不是正确率，局部检查不构成通用语义证明。缺证据、不匹配或超预算均跳过。

terminal_prefix只能替换未被局部可靠证据保护的第3–5位文档；被替换文档仍留在原Top10内。因此局部后处理的R@1/R@2/R@10/R@20/R@200保持，R@5仍须实测。terminal_tail可能替换原Top10内文档，R@10不作无条件保证。前置规划变化会改变检索结果，不属于上述局部排名保障。

末端选择与比较剪枝不新增LLM或搜索请求。原子链规划会改变子问题并可能增加检索／核验，仍受原节点6、深度4、搜索与并发预算限制。不会强制生成与hop相同数量的节点；明确时间／地点终端属性错置进入已有最多两次修复。

## 退化保护与目标

主要增益目标沿用R@5/R@10增加0.04，不因指标上限或实测调整。验收扩大为全部导出Recall：

```text
R@1 / R@2 / R@5 / R@10 / R@20 / R@200
```

每个数据集、每个阶段都与同批原exp4配对比较。原始均值和按总体主类型比例加权的均值，两者每项下降均不得超过0.01。超过门槛的方案保留真实结果和失败明细，但不进入候选确认或标记有效。All gold@5/@10原始增量另行记录，不属于当前Recall保护规则。

这是样本层面的检查，不能保证每道题或尚未测过的全量数据不退化。若筛选候选全部违规，直接结束小批量实验；若确认违规，也不会自动启用该方案或启动全量。

## 独立代表性样本

每个数据集60题筛选、另外30题确认。排除旧三轮216题和上一轮structure_representative的90题，共306题，剩余池694题。显式记录排除来源及SHA；不扫描当前namespace，确保续跑样本固定。

沿用Hotpot两类、2Wiki四类、MuSiQue六种规范DAG主层，兼顾hop、gold数量、末端属性及交叉类别。screen seed=542、confirmation seed=642。完整采样覆盖与缺项保存到sampling报告；几十题不能保证覆盖全部语义或消除全部偏差，仍属于现有评估文件上的开发实验。

先运行9组两题集成检查，其中原exp4缓存重放必须Top10一致；随后18组60题筛选（原exp4＋5方案×3数据集）。通过退化保护的候选最多选两组，在新的30题上确认；按逐题Recall与Top10实际排序去重，等价方案只确认一份。

总计27组固定实验，另加0、6或9组确认，最多36组。不会自动启动全量或QA。

## 运行与保存

vLLM使用vllm环境，评估使用rag环境及已有Qwen3运行依赖。恢复服务沿用上轮Qwen3-8B、8192上下文、bfloat16、显存比例0.6；每次客户端请求2048输出上限、thinking关闭。embedding Qwen3-Embedding-8B batch=4，LLM/OpenIE并发=8，公共索引保持复用。

```bash
bash scripts/run_exp4_round2.sh --mode all \
  --run-tag failure_focused --sampling-policy representative \
  --exclude-run-tags structure_representative \
  --screen-size 60 --confirm-size 30 --screen-seed 542 --confirm-seed 642 \
  --variants terminal_tail,terminal_prefix,plan_prune,chain_atomic,chain_terminal \
  --protected-metrics Recall@1,Recall@2,Recall@5,Recall@10,Recall@20,Recall@200 \
  --require-raw-guard
```

- 采样报告：上述目录下`sampling/{dataset}.json`。
- 每组结果：`_exp4_round2_trials_failure_focused/{smoke,screen,confirmation}/{dataset}/{variant}`。
- 日志：`logs/run_exp4_round2.log`；launcher另存`logs/launcher_failure_focused.log`。
- 完整Top10、Top200、trace、report、manifest与校验凭据保留；验证完成只清理私有索引副本。

各方案共用阶段原exp4完成后的私有缓存快照，热缓存耗时不作为公平冷缓存效率结论。算法、脚本、数据、来源索引及采样都记录SHA，开始正式实验后保持源码冻结。
